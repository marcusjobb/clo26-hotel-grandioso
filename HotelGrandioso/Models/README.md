# Models

Här ligger klasser som representerar det ni hanterar i appen (till exempel `Patient`, `Ägare`, `Budgetpost`).

- En klass per fil, med samma namn som filen.
- Modeller innehåller data och enkel logik. De ska inte veta hur de sparas.
- Ta bort den här filen när ni lagt in era egna klasser, om ni vill.
