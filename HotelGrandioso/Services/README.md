# Services

Här ligger logiken som kopplar ihop modeller och data.

- **Repository** (obligatoriskt eller motiverat bort, se uppgiften): en klass som samlar läs- och skrivoperationer mot databasen, så att resten av programmet inte behöver veta hur data sparas.
- Övriga tjänster (till exempel Factory, Builder eller Observer) placeras här om de hör till logiken.
